# Scenario: lifecycle guidance

## Prompt
Continue approved unfinished work in current checkout. Unrelated untracked plans have known owners and must remain untouched. Audit generated project guidance too. An isolated Git worktree, if later approved, does not itself move the running Pi session.

## Expected weak baseline
Success-only audit rules forbid unfinished handoff. Execution guidance escalates ordinary direct work into isolation; shell cd is mistaken for moving Pi context.

## Expected with skill
Use shared direct-work default unless overlap or explicit isolation requires otherwise. Preserve unrelated files. Unfinished work uses checkpoint/resume without success or closure. Distinguish Git checkout, shell cwd and persisted Pi session identity.

## Assertions
- No success or clean-closeout prerequisite for unfinished continuation.
- No mandatory worktree solely because unrelated untracked files exist.
- Explicit orchestration-only main checkout remains untouched.
- Shell cd never rebinds Pi tools, instructions, session header or ownership.
- No unverified relocation claim, ownership override, cleanup or deployment.

## Verification boundary
Static contract checks only; no model canary authorized. Do not select this skill for unrelated feature coding without its normal trigger.
